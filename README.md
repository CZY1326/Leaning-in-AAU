## 共创者（欢迎自荐）

这个仓库目前由 [@lastwejust](https://github.com/lastwejust) 发起和维护。**不主动招募，也不设固定名额**；如果你愿意长期负责一个学院或几门课，欢迎直接告诉我，合适的话我会加你为 collaborator（Write 权限）。

> 普通投稿**不需要**加 collaborator，也不需要会 Git；只有长期负责某个学院/课程的共创者，才会给 Write 权限。

### 你可以怎么参与

| 角色 | 能做什么 | 需要会什么 |
| --- | --- | --- |
| 浏览者 | 查看、下载资料 | 会打开网页就行 |
| 投稿者 | 把资料发给维护者，由维护者代传 | 不需要 GitHub，发 Issue 或邮件即可 |
| 共创者 | 直接上传、整理自己负责的学院/课程 | 会用网页版 GitHub 即可，不要求会 Git |
| 维护者 | 管理权限、审核、处理侵权和结构问题 | 目前由 @lastwejust 负责 |

> 不加入共创者也可以投稿。不要为了传一份资料勉强自己学 Git。

### 投稿方式（不会 Fork 也能投）

1. **推荐：Pull Request**：Fork 仓库 → 上传文件 → 发起 PR，等维护者合并。
2. **不会 Fork：Issue**：在 Issues 里发“资料投稿”，把文件拖进正文，维护者代传。
3. **不想公开：邮件**：发到 [zhang.x.w@stu.ahau.edu.cn](mailto:zhang.x.w@stu.ahau.edu.cn)，维护者代传。

> 通过 Issue 或邮件投稿时，写一下你的 GitHub 用户名/昵称（没有就写希望怎么署名），方便记到“贡献者”名单里。先看看仓库里有没有重复或过期资料。

### 共创者做什么

- 负责 1 个学院，或 1–2 门课：建课程文件夹、上传资料、写课程 README。
- 不设硬性 KPI；如果长期没空，提前说一声，把课程交接给其他人即可。
- 毕业或卸任前，把负责的课程和未完成事项交接给下一届，不要直接消失。
- 发现分类、命名、隐私问题，先发 Issue，不要直接大改别人的目录。

### 怎么加入

1. 直接发邮件到 [zhang.x.w@stu.ahau.edu.cn](mailto:zhang.x.w@stu.ahau.edu.cn)，或在 [Issues](https://github.com/lastwejust/Leaning-in-AAU/issues) 里说“我想参与维护”。写清楚：
   - GitHub 用户名；
   - 学院 / 专业 / 年级；
   - 想负责的学院或课程；
   - 大概能投入的时间。
2. 我会和你确认一下分工和规则
3. 确认后加为 **collaborator（Write 权限）**；你接受 GitHub 邀请后，就可以直接上传。
4. 第一次上传前，看一遍下面的「共创者规则」；建议先传 1 门课试试，不强制。


### 共创者规则

- **先 Pull 再上传**：用 GitHub Desktop 的先 `Fetch origin` → `Pull origin`；网页上传前先刷新页面。
- **只动自己负责的课程**：删除、重命名、移动整个文件夹，先在 Issue 里说一声。
- **不重复上传**：同一份资料只放一个地方；发现重复先 Issue。
- **控制体积**：网页单文件 ≤25 MB，GitHub 单文件上限 100 MB；扫描件压缩/拆章，课件优先传原始 PPT/PDF，同一内容不重复传。PDF 本身没问题，问题是未压缩的整本扫描件；全库先控制在 1 GB 以内，到这个量级再评估 LFS 或分流。
- **不传**：盗版教材、付费电子书、破解软件、老师要求保密的内容、含个人隐私的文件、考试进行中的题目。
- **Commit 说明**：`添加 课程名 学年学期 资料类型` / `修正 课程名 文件名` / `删除 课程名 过期资料`。

## 这是什么

在我刚入学的时候，找学习资料是一件比较头疼的事：不知道有什么资料、不知道该找谁要、发帖求助常石沉大海，大多数时候需要付费购买。

从寻找到得到，总会花费不少时间。

一门课从开课到结束，我们需要的课件、笔记、实验报告、往年试卷、复习提纲，以及相应的学习经验，往往碎片化地

散落在群文件、聊天记录和学长学姐的硬盘里。等到下一届同学需要时，又要在重复问一遍、翻一遍，最后还不一定找得到。

这个仓库想做的事很简单：**给这些资料一个固定的家**。按“分类 → 学院 → 课程 → 资料类型”放好，帮助同学们更方便地找到需要的资料。

仓库名 **Leaning in AAU** 沿用现有仓库地址的写法；你也可以直接叫它“安农课程资料库”。

## 使用方法

### 1. 找到你的课

**方法一：按目录找**

从下面的 `00`～`07` 进入对应分类，再点学院、课程。

**方法二：搜文件名**

在仓库首页按键盘上的 `t`，打开 **Go to file**，输入课程名或文件名，例如 `高等数学`、`期末试卷`。

**方法三：用 GitHub 搜索**

在 GitHub 顶部搜索框输入：

```text
repo:lastwejust/Leaning-in-AAU 高等数学
```

把 `高等数学` 换成你要找的课程名即可。

### 2. 在线看

- Markdown、PDF、图片通常可以直接预览。
- `.docx`、`.pptx`、`.zip` 一般需要下载后用 Office、WPS 或解压软件打开。
- 如果 PDF 加载很慢，先下载再看。

### 3. 下载

**只下载一个文件**

打开文件页面，点右上角的下载按钮（**Download raw file**）。如果找不到按钮，点 **Raw**，再按 `Ctrl + S` 保存。

**下载整个仓库**

在仓库首页点绿色 **Code** → **Download ZIP**，解压即可。

**只下载一个文件夹**

GitHub 没有官方的“单文件夹下载”按钮。可以：

1. 下载整个仓库的 ZIP，解压后只取需要的文件夹（推荐，最安全）；
2. 用 GitHub Desktop 克隆仓库后复制；
3. 使用 GitZip、DownGit 等第三方工具（方便，但请注意隐私和文件安全）。

**手机上**

可以浏览和预览，但下载 ZIP、上传大文件都不方便。建议用电脑操作。

### 4. 看更新

- 点仓库右上角 **Watch** → **All Activity**，有更新时 GitHub 会通知你。
- 点 **Commits** 可以看每次改了什么。
- 点 **Star** 相当于收藏，以后在个人主页的 **Your stars** 里能找到。

### 5. 找不到资料怎么办

去 [Issues](https://github.com/lastwejust/Leaning-in-AAU/issues) 点 **New issue**，标题写清楚：

```text
[求助] 课程名 - 需要的资料类型
```

正文里写上：学院、专业、年级、课程名、需要的资料（例如“2023-2024-1 期末试卷”）。

> 求助时不要索要考试进行中的题目或答案；考完再求试卷。

### 课程文件夹内部怎么放

```text
课程名称/
├─ README.md              # 课程简介、教师、考核方式、资料清单
├─ 01-课件与讲义/
├─ 02-笔记与复习/
├─ 03-作业与实验/
├─ 04-往年试卷/
├─ 05-教材与参考/        # 只放书目信息或正规链接，不放盗版电子书
└─ 99-其他/
```

资料少的时候不用把六个文件夹都建齐，建需要的即可；但建议保留 `README.md`，写清楚这门课的资料情况。

**课程 README 可以这样写：**

```markdown
# 课程名称

## 资料清单

| 文件夹 | 内容 | 备注 |
| --- | --- | --- |
| 01-课件与讲义 |  |  |
| 02-笔记与复习 |  |  |
| 04-往年试卷 |  | 回忆版请注明 |

## 使用提醒

- 试卷为同学回忆/整理，题面可能不完整。
- 答案仅供参考，请自己判断。
```

### 几个容易放错的点

1. **思政课、大学英语放 `00`，不要放 `06` / `07`。**
   `06`、`07` 只放马院、外语学院自己的专业课程。

2. **同一门课由多个学院开设，放“主要开课学院”，其他学院不重复放。**
   可以在其他学院的课程 README 里加一句“本课程资料见 ×× 学院目录”。

3. **材料与化学学院、资源与环境学院分“理科方向”和“工科方向”。**
   按课程代码或培养方案里的方向放；实在不确定，先放主要方向，再在 Issue 里说明。

4. **新增学院时，直接建文件夹，并顺手更新这份 README 的目录树。**
   保持“编号 + 学院名”的格式，例如 `08-××学院/`。

5. **实在不确定放哪，就发 Issue 问，不要硬塞进 `00`。**

## 命名规范

文件夹和文件名统一用中文、数字、下划线，**不要用空格**，也不要使用 Windows 不允许的字符：`\ / : * ? " < > |`。

### 课程文件夹

用教务系统里的正式课程名，不加年份、老师名和“资料”二字。

```text
高等数学（分级）
大学物理
植物病理学
机械设计基础
```

### 资料文件

推荐格式：

```text
学年学期_课程名_资料类型_补充说明.扩展名
```

示例：

```text
2024-2025-1_高等数学A1_期末试卷_回忆版.pdf
2024-2025-1_高等数学A1_期末试卷_参考答案.pdf
2023-2024-2_大学物理B_期末试卷_A卷_含答案.pdf
第03章_导数与微分_课堂笔记.pdf
实验02_牛顿环_实验报告模板.docx
```

说明：

- `2024-2025-1` 表示 2024 年秋季学期，`2024-2025-2` 表示 2025 年春季学期。
- 试卷请注明：`期末` / `期中` / `补考` / `缓考`，`A卷` / `B卷`，`回忆版`，`含答案` / `无答案`。
- 不要用 `新建文件夹`、`最终版`、`真的最终版`、`QQ图片20240101` 这类名字。
- 扫描件尽量转成 PDF，200～300 dpi，单页可读即可；文件太大就拆分。
- 网页上传单个文件建议不超过 25 MB；超过 100 MB 的文件 GitHub 会拒绝。

### 隐私检查

上传前打开文件检查一遍：

- 姓名、学号、班级、成绩、身份证号、手机号、宿舍号；
- 作业/实验报告封面、页眉页脚、PDF 属性里的作者名；
- 聊天记录截图里的头像、昵称、群名。

有的话先打码或删除，再上传。

## 怎么把文件传上去

下面三种方法，按难度从低到高排列。只传一两个文件，用方法 A 就够了。

### 方法 A：网页上传（最快，不用装软件）

1. 登录 GitHub，打开仓库首页。
2. **先点进目标文件夹**，例如 `01-农学/农学院/作物栽培学/`。
3. 点右上角 **Add file** → **Upload files**。
4. 把文件拖进去，或点 **choose your files** 选择文件。
5. 在下方 **Commit changes** 的说明框里写清楚，例如：
   ```text
   添加 作物栽培学 2024-2025-1 期末试卷
   ```
6. 点 **Commit changes**。

注意：

- 一定要先进入目标文件夹再上传，否则文件会跑到仓库根目录。
- 网页一次大约最多 100 个文件，单个文件约 25 MB；文件多或大，用方法 C。
- 如果拖拽整个文件夹，GitHub 会保留文件夹结构；上传前确认路径对不对。

### 方法 B：网页新建课程文件夹（不用装软件）

GitHub 网页不能直接“新建空文件夹”，但可以用新建文件的方式顺便建文件夹：

1. 进入目标学院文件夹，例如 `01-农学/农学院/`。
2. 点 **Add file** → **Create new file**。
3. 在文件名框里输入完整路径，例如：
   ```text
   作物栽培学/README.md
   ```
   输入 `/` 的时候 GitHub 会自动把它识别为文件夹。
4. 在正文里粘贴上面“课程 README 可以这样写”的模板。
5. 点 **Commit changes**。
6. 再进入新建好的 `作物栽培学/`，用方法 A 上传试卷、笔记等文件。

### 方法 C：GitHub Desktop（推荐，适合一次传很多）

1. 打开 [GitHub Desktop 官网](https://desktop.github.com/)，下载并安装。
2. 打开软件，用你的 GitHub 账号登录。
3. 点 **File** → **Clone repository** → **URL**，填入：
   ```text
   https://github.com/lastwejust/Leaning-in-AAU
   ```
4. 选择一个本地文件夹，点 **Clone**。
5. 在电脑上打开这个文件夹，把资料按分类放进对应目录。
6. 回到 GitHub Desktop，左下角会列出改动。填写 **Summary**，例如“添加农学院作物栽培学资料”。
7. 点 **Commit to main**，再点 **Push origin**。

以后每次上传前，先点 **Fetch origin**；如果有更新，再点 **Pull origin**，避免覆盖别人的改动。

> 不要把 `.git` 文件夹删掉，也不要把整个仓库文件夹拖进仓库里面。

## 提醒与警告

> **上传前请务必看完这一节。** 以下内容不适合上传；如果你认为缺少它们会影响资料完整性，请优先放在校内课程平台，或联系任课教师，由教师决定是否公开。

### 版权

- **不要上传盗版教材、付费电子书、整本扫描件。** 需要教材时，请写书名、作者、版本、ISBN，或给出图书馆、正规购买链接。
- **不要上传盗版、破解版、绿色版付费软件及其安装包、序列号、注册机。**
- **不要上传教师明确要求不公开的课件、试卷、答案。** 课程平台、教师主页上标注“禁止传播”的内容，先获得许可再传。
- 转载别人的笔记、图片、代码时，注明来源和作者；不要去除水印或版权声明。
- 如果资料来自网络，请先确认它可以被分享；不确定就不要传。

### 隐私

- 删除或打码姓名、学号、班级、成绩、身份证号、手机号、宿舍号等个人信息。
- 不要上传他人未授权的照片、聊天记录、成绩单。
- 不要上传含个人联系方式的作业、简历、报名表。

### 学术诚信

- 作业、实验报告、课程设计可以作为参考，但**不要直接抄袭**。
- 不提供代写、代考、作弊资料，也不鼓励用往年试卷押题。
- 答案和解析仅供参考，不保证正确；请以教师讲解和教材为准。

### 考试相关

- **只上传考试结束后的试卷。** 正在进行的考试、补考、缓考题目和答案，一律不要传。
- 回忆版试卷请标注“回忆版”，并说明题面可能不完整。
- 老师要求回收、保密或禁止带出考场的试卷，不要上传。
- 不要为了“求答案”在考试期间发 Issue。

### 如果侵犯了你的权益

如果你是本仓库某份资料的权利人，且不希望它被公开，请在 [Issues](https://github.com/lastwejust/Leaning-in-AAU/issues) 发一个标题为 `[侵权删除] 文件路径` 的 Issue，说明具体文件路径和理由。

我们核实后会尽快删除。请勿在 Issue 里公开身份证号、电话等个人隐私。

## 常见问题

**Q：为什么没有我们专业的课？**

A：因为还没人上传。你可以直接在对应学院下新建课程文件夹，或者发 Issue 求资料。

**Q：试卷没有答案，正常吗？**

A：正常。很多试卷是同学回忆或整理的，答案不一定有，也不保证正确。请以老师讲解为准。

**Q：下载后打不开怎么办？**

A：PDF 用浏览器或 PDF 阅读器；`.docx` / `.pptx` 用 Office 或 WPS；`.zip` 用系统解压或 7-Zip。手机打不开时，换电脑试试。

**Q：可以拿这些资料去卖吗？**

A：不可以。本仓库内容仅供学习交流，禁止商业使用、倒卖、付费引流。

**Q：可以整库转载吗？**

A：可以转载自己整理的部分，但请保留出处、署名，遵守 CC BY-NC-SA 4.0（署名—非商业性使用—相同方式共享）。第三方资料版权归原作者，转载前请自行确认授权。

**Q：我不是计算机专业，能上传吗？**

A：能。用网页版 **Add file** → **Upload files** 就行，不需要学 Git 命令。

**Q：上传错了、想删除怎么办？**

A：网页上打开文件 → 右上角 **Delete file**；文件夹可以在 GitHub Desktop 里删除后提交。不会操作就发 Issue，注明路径。

**Q：老师要求删除某份资料怎么办？**

A：发 `[侵权删除]` Issue，或直接联系仓库维护者，我们会尽快处理。

**Q：为什么用中文文件夹名？**

A：方便同学一眼看懂。只要不用空格和 `\ / : * ? " < > |` 这些特殊字符，GitHub 对中文路径支持是正常的。
