# 参与共建

<a id="submit"></a>

## 投稿方式

不需要会 Git，也不需要先加权限。

### 方式一：Pull Request（推荐）

1. 点右上角 **Fork**，复制一份到你的账号。
2. 在 Fork 里进入对应文件夹，点 **Add file** → **Upload files**。
3. 上传后点 **Contribute** → **Open pull request**。
4. 等维护者审核合并。

### 方式二：Issue

在 [Issues](https://github.com/lastwejust/Leaning-in-AAU/issues) 发“资料投稿”，把文件拖进正文，维护者代传。

### 方式三：邮件

发到 [zhang.x.w@ahau.edu.cn](mailto:zhang.x.w@ahau.edu.cn)，写清楚课程名、资料类型、年份。

> 含隐私或不想公开的资料走邮箱，不要发 Issue。  
> 通过 Issue/邮件投稿时，写一下 GitHub 用户名/昵称，方便记到贡献者名单。

<a id="cobuild"></a>

## 共创者（欢迎自荐）

这个仓库目前由 [@lastwejust](https://github.com/lastwejust) 发起和维护。**不主动招募，也不设固定名额**；如果你愿意长期负责一个学院或几门课，欢迎直接告诉我，合适的话我会加你为 collaborator（Write 权限）。

> 普通投稿**不需要**加 collaborator；只有长期负责某个学院/课程的共创者，才会给 Write 权限。

| 角色 | 能做什么 | 需要会什么 |
| --- | --- | --- |
| 浏览者 | 查看、下载资料 | 会打开网页就行 |
| 投稿者 | 把资料发给维护者，由维护者代传 | 不需要 GitHub，发 Issue 或邮件即可 |
| 共创者 | 直接上传、整理自己负责的学院/课程 | 会用网页版 GitHub 即可 |
| 维护者 | 管理权限、审核、处理侵权和结构问题 | 目前由 @lastwejust 负责 |

<a id="join"></a>

## 怎么加入

1. 发邮件到 [zhang.x.w@ahau.edu.cn](mailto:zhang.x.w@ahau.edu.cn)，或在 [Issues](https://github.com/lastwejust/Leaning-in-AAU/issues) 说“我想参与维护”。写清楚：
   - GitHub 用户名；
   - 学院 / 专业 / 年级；
   - 想负责的学院或课程；
   - 大概能投入的时间。
2. 我会和你确认分工和规则（不考试、不用写申请信）。
3. 确认后加为 **collaborator（Write 权限）**；接受 GitHub 邀请后就能直接上传。
4. 第一次上传前看一遍下面的规则；建议先传 1 门课试试，不强制。

<a id="rules"></a>

## 共创者规则

- **先 Pull 再上传**：GitHub Desktop 先 `Fetch origin` → `Pull origin`；网页上传前先刷新。
- **只动自己负责的课程**：删除、重命名、移动整个文件夹，先在 Issue 说一声。
- **不重复上传**：同一份资料只放一个地方。
- **控制体积**：网页单文件 ≤25 MB，GitHub 单文件上限 100 MB；扫描件压缩/拆章，同一内容不重复传。全库先控制在 1 GB 以内。
- **不传**：盗版教材、付费电子书、破解软件、老师要求保密的内容、含个人隐私的文件、考试进行中的题目。
- **Commit 说明**：`添加 课程名 学年学期 资料类型` / `修正 课程名 文件名` / `删除 课程名 过期资料`。
