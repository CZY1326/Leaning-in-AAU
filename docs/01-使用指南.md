# 使用指南

<a id="find"></a>

## 1. 找课

### 按目录找

从仓库首页的 `00`～`07` 进入分类，再点学院、课程。

### 搜文件名

在仓库首页按键盘上的 `t`，打开 **Go to file**，输入课程名或文件名，例如 `高等数学`、`期末试卷`。

### 用 GitHub 搜索

在 GitHub 顶部搜索框输入：

```text
repo:lastwejust/Leaning-in-AAU 高等数学
```

<a id="view"></a>

## 2. 在线看

- Markdown、PDF、图片通常可以直接预览。
- `.docx`、`.pptx`、`.zip` 一般需要下载后用 Office、WPS 或解压软件打开。
- PDF 加载慢时，先下载再看。

<a id="download"></a>

## 3. 下载

### 只下载一个文件

打开文件页面，点右上角的下载按钮（**Download raw file**）。  
如果找不到按钮，点 **Raw**，再按 `Ctrl + S` 保存。

### 下载整个仓库

在仓库首页点绿色 **Code** → **Download ZIP**，解压即可。

### 只下载一个文件夹

GitHub 没有官方的“单文件夹下载”按钮。可以：

1. 下载整个仓库的 ZIP，解压后只取需要的文件夹（推荐）；
2. 用 GitHub Desktop 克隆后复制；
3. 用 GitZip、DownGit 等第三方工具（注意隐私和文件安全）。

### 手机上

可以浏览和预览；下载 ZIP、上传大文件建议用电脑。

<a id="update"></a>

## 4. 看更新

- 点仓库右上角 **Watch** → **All Activity**，有更新时 GitHub 会通知你。
- 点 **Commits** 看每次改了什么。
- 点 **Star** 收藏，以后在个人主页的 **Your stars** 里能找到。

<a id="help"></a>

## 5. 找不到资料怎么办

去 [Issues](https://github.com/lastwejust/Leaning-in-AAU/issues) 点 **New issue**，标题写：

```text
[求助] 课程名 - 需要的资料类型
```

正文写：学院、专业、年级、课程名、需要的资料。

> 不要索要考试进行中的题目或答案；考完再求试卷。
