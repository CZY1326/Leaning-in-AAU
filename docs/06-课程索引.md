## 在 GitHub 上按课程找

1. 点上面的目录链接，进入分类；
2. 点学院文件夹；
3. 点课程文件夹；
4. 点开文件，右上角下载。

如果文件夹很多，按键盘 ++t++ 直接搜课程名更快。

## 索引维护模板

以后加新课程，按这个格式往上面表格里加一行：

```markdown
| [课程名](https://github.com/lastwejust/Leaning-in-AAU/tree/main/路径) | 试卷、笔记 |
```
